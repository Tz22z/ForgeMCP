# ForgeMCP

ForgeMCP is a repository-level coding agent that turns a software issue into a
tested patch. It combines an incremental code index, budget-aware context
selection, a plan–act–verify loop, and policy-checked tools exposed through MCP.

The project is built around one question: **what changes to an agent runtime make
multi-file fixes more reliable and less expensive when the model and budget stay
fixed?**

> This repository reconstructs work whose original local Git object database was
> lost. Reconstructed commits are labeled in their commit trailers.

## Status

The implementation is being reconstructed milestone by milestone. See
`docs/architecture.md` and `docs/evaluation.md` as they land.
